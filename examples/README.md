# nicefigs examples

Each script here is a small, self-contained, copy-pasteable demonstration of one
plot family, using only the deterministic synthetic data in
`nicefigs.data`. Run one on its own to write its figure into the current
directory:

```bash
python examples/01_global_map.py      # writes 01_global_map.png and .pdf
```

or render the whole gallery into `docs/gallery/` at once:

```bash
python examples/render_gallery.py
```
